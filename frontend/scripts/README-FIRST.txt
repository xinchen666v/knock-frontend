knock - Windows 客户端
======================

1. 解压整个文件夹后运行 knock.exe。
   不要只复制 knock.exe：data 目录、flutter_windows.dll、sqlite3.dll 都必须保留。

2. 不需要设置任何环境变量。
   首次启动会自动生成本机身份；身份、联系人、聊天记录只保存在这台电脑上。

3. 服务器
   欢迎页“创建一扇门”下方显示当前服务器，默认：
       47.254.238.173:7801
   点击那一行可以修改。它用于创建新门；
   加入别人发来的邀请链接时，会使用链接里带的服务器地址。

4. 使用方式
   创建一扇门 -> 把邀请链接/二维码发给对方；
   或“我有邀请链接” -> 粘贴对方的链接。
   聊天页左上角可返回联系人列表；聊天记录保留最近 30 天。

5. 常见问题
   - Windows 提示“已保护你的电脑”：这是未签名程序的 SmartScreen 提示，
     点“更多信息” -> “仍要运行”。
   - 提示缺少 MSVCP140.dll / VCRUNTIME140.dll：
     安装 Microsoft Visual C++ 2015-2022 Redistributable (x64)，
     或确认本目录中的三个 VC++ DLL 没有被杀毒软件隔离。
   - 需要 64 位 Windows 10/11。
   - 本压缩包只包含客户端；服务端需另行部署或使用默认云服务器。
